# Feature documentation

These documents describe branch-specific features that are not yet part of an AREDN production release.

- [Multi-WAN USB WAN and PdaNet setup](multiwan-usb-wan.md) — administrator setup, proxy behavior, calibration, verification, and troubleshooting for `wan3` on the MikroTik hAP ac lite, hAP ac2, and hAP ac3.
- [Multi-WAN link calibration design](multiwan-link-calibration.md) — authentication, Hurricane Electric / Hayward CDN contract, bounded transfer sizes, and link classification.

Documentation and implementation are expected to change together. The USB WAN guide contains a code-to-document verification map tying each user-visible behavior to its source file.
